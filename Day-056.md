# Day 056: Feature Engineering

## What I Learned

Today I learned about **Feature Engineering**, one of the most important parts of a Machine Learning workflow.

Feature Engineering is the process of creating, transforming, selecting, and modifying features so that Machine Learning models can learn useful patterns more effectively.

---

## What is a Feature?

A feature is an input variable used by a Machine Learning model.

For example, in a house price prediction problem:

```text
Area
Bedrooms
Age
```

are features.

The value we want to predict:

```text
Price
```

is the target.

---

## What is Feature Engineering?

Feature Engineering means transforming raw data into useful representations for Machine Learning models.

The basic idea is:

```text
Raw Data
   ↓
Feature Engineering
   ↓
Useful Features
   ↓
Machine Learning Model
```

Good features can significantly improve model performance.

---

## 1. Creating New Features

New features can be created from existing information.

For example:

```text
Height
Weight
```

can be used to create:

```text
BMI
```

Another example is extracting age from a date of birth.

---

## 2. Mathematical Transformations

Some numerical features can benefit from transformations.

Examples include:

* Log transformation
* Square root transformation
* Polynomial features
* Reciprocal transformations

For example:

```text
Income
```

can sometimes be transformed using:

```text
log(Income)
```

to compress a large numerical range.

---

## 3. Encoding Categorical Features

Machine Learning algorithms often require numerical input.

Categorical values such as:

```text
Red
Blue
Green
```

can be represented using **One-Hot Encoding**:

```text
Red   Blue   Green
 1     0      0
 0     1      0
 0     0      1
```

---

## 4. Ordinal Encoding

When categories have a meaningful order, ordinal encoding can be used.

Example:

```text
High School → 1
Bachelor    → 2
Master      → 3
PhD         → 4
```

This should only be used when the ordering is meaningful.

---

## 5. Feature Scaling

Features can have very different numerical ranges.

For example:

```text
Age     → 18–80
Salary  → 20,000–2,000,000
```

Scaling can transform features into comparable ranges.

### Standardization

Generally transforms a feature to:

```text
Mean ≈ 0
Standard Deviation ≈ 1
```

### Min-Max Scaling

Transforms values into a chosen range, commonly:

```text
0 → 1
```

---

## Do All Models Need Scaling?

No.

Scaling is particularly useful for algorithms such as:

* Logistic Regression
* KNN
* SVM
* Neural Networks

Tree-based algorithms such as:

* Decision Trees
* Random Forest
* XGBoost
* LightGBM
* CatBoost

generally do not require feature scaling in the same way.

---

## 6. Handling Missing Values

Real-world datasets often contain missing values.

Example:

```text
Age      Salary
25       50K
NaN      60K
30       NaN
```

Possible approaches include:

* Removing rows
* Removing features
* Mean imputation
* Median imputation
* Mode imputation
* Model-based imputation
* Algorithms that support missing values

The correct approach depends on the dataset and problem.

---

## 7. Feature Selection

Feature Selection means choosing the most useful features for the model.

For example:

```text
100 Features
      ↓
Remove irrelevant/redundant features
      ↓
30 Useful Features
```

Removing irrelevant features can reduce noise and model complexity.

---

## 8. Removing Redundant Features

Some features contain almost identical information.

For example:

```text
Age
Age_in_months
```

These may be redundant.

Similarly:

```text
Price in Rupees
Price in Thousands
```

represent the same underlying information.

---

## 9. Date and Time Features

Dates contain useful information that can be extracted.

For example:

```text
Purchase_Date
```

can become:

```text
Day
Month
Year
Day_of_week
Weekend
Quarter
Holiday
```

These engineered features may be more useful than the raw date itself.

---

## 10. Text Features

Text can also be converted into useful features.

For example:

```text
"This product is amazing!"
```

Possible features include:

```text
Word Count
Character Count
Sentiment
TF-IDF
Embeddings
```

This connects Feature Engineering with Natural Language Processing.

---

## Data Leakage

Data leakage occurs when information that should not be available during prediction is accidentally used during training.

For example, if we are predicting whether a customer will default on a loan, using information that becomes available only after the default would create leakage.

This can make the model appear highly accurate while performing poorly in real-world use.

---

## Train/Test Leakage

A common mistake is applying preprocessing to the entire dataset before splitting.

Incorrect:

```text
Entire Dataset
      ↓
Scale
      ↓
Train/Test Split
```

This can allow information from the test set to influence the transformation.

A safer approach is:

```text
Dataset
   ↓
Train/Test Split
   ↓
Fit transformation on Training Data
   ↓
Apply transformation to Test Data
```

The test set should remain unseen during model development.

---

## Feature Engineering vs Feature Selection

### Feature Engineering

Creating or transforming features.

Example:

```text
Height + Weight
      ↓
BMI
```

### Feature Selection

Choosing which features should be retained.

Example:

```text
100 Features
      ↓
30 Useful Features
```

---

## Example: Food Delivery Prediction

Suppose we want to predict delivery time.

Raw data:

```text
Restaurant
Distance
Order_Time
Weather
Traffic
Number_of_Items
```

We can engineer:

```text
Distance
Hour_of_Day
Is_Weekend
Rainy
Traffic_Level
Items_per_Order
```

We could also create interaction features such as:

```text
Traffic × Distance
```

These features may better represent the factors affecting delivery time.

---

## Feature Engineering Pipeline

A typical workflow is:

```text
Raw Data
   ↓
Understand Features
   ↓
Handle Missing Values
   ↓
Encode Categories
   ↓
Create Useful Features
   ↓
Transform Features
   ↓
Select Features
   ↓
Train Model
   ↓
Evaluate
```

Transformations should be learned from the training data and then applied to validation/test data to avoid leakage.

---

## Key Takeaways

* Features are inputs used by Machine Learning models.
* Feature Engineering converts raw data into useful representations.
* New features can be created from existing features.
* Categorical features may need encoding.
* Numerical features can sometimes benefit from scaling or transformations.
* Feature Selection removes unnecessary or irrelevant features.
* Date and text data can be transformed into useful features.
* Data leakage must be avoided.
* Good feature engineering can significantly improve model performance.

---

## Why This Matters

Feature Engineering is one of the most practical Machine Learning skills.

A sophisticated algorithm cannot compensate for poor or misleading input features.

Understanding how to represent information properly is therefore just as important as understanding the Machine Learning algorithm itself.
