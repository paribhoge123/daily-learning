# Day 058: Dimensionality Reduction & PCA

## What I Learned

Today I learned about **Dimensionality Reduction** and **Principal Component Analysis (PCA)**.

Dimensionality Reduction reduces the number of dimensions/features in a dataset while attempting to preserve the most important information.

---

## What is Dimensionality?

The number of features in a dataset is often referred to as its dimensionality.

For example:

```text
Age
Salary
Experience
```

represents:

```text
3 Dimensions
```

A dataset with 500 features has 500 dimensions.

---

## What is Dimensionality Reduction?

Dimensionality Reduction is the process of reducing the number of dimensions while preserving as much useful information as possible.

Example:

```text
100 Features
     ↓
Dimensionality Reduction
     ↓
10 Components
```

---

## Why Do We Need Dimensionality Reduction?

High-dimensional datasets can cause:

* Increased computational cost
* Increased memory requirements
* Difficulty in visualization
* Redundancy
* Noise
* Curse of Dimensionality

Reducing dimensions can make the dataset easier to analyze and sometimes improve computational efficiency.

---

# Feature Selection vs Dimensionality Reduction

## Feature Selection

Feature Selection keeps a subset of the original features.

```text
Age
Salary
Height
Weight
Experience

        ↓

Age
Salary
Experience
```

The original features remain unchanged.

---

## Dimensionality Reduction

Dimensionality Reduction creates new representations/components.

```text
Age
Salary
Height
Weight
Experience

        ↓

PC1
PC2
```

The new components are combinations of the original features.

---

# Principal Component Analysis (PCA)

PCA stands for **Principal Component Analysis**.

It is an unsupervised dimensionality reduction technique.

PCA transforms the original features into new variables called **Principal Components**.

The components are ordered based on how much variance they capture.

---

## Principal Components

### PC1

Captures the maximum possible variance.

### PC2

Captures the maximum remaining variance while being orthogonal to PC1.

### PC3

Captures the next largest amount of remaining variance.

And so on.

---

## Explained Variance

The Explained Variance Ratio tells us how much variance is captured by each principal component.

Example:

```text
PC1 → 70%
PC2 → 20%
PC3 → 7%
PC4 → 3%
```

If we keep PC1 and PC2:

```text
70% + 20% = 90%
```

So two components preserve approximately 90% of the original variance.

---

## Mathematical Intuition

PCA is based on finding directions of maximum variance.

A simplified process is:

```text
Covariance Matrix
       ↓
Eigenvalues + Eigenvectors
       ↓
Principal Components
```

### Eigenvectors

Determine the directions of the principal components.

### Eigenvalues

Represent the amount of variance associated with those directions.

---

## Scaling Before PCA

PCA is sensitive to feature scale.

Suppose:

```text
Age       → 18–80
Salary    → 20,000–2,000,000
```

Salary has a much larger numerical range and can dominate the variance calculation.

Therefore, features are generally standardized before applying PCA.

A typical pipeline is:

```text
Raw Data
   ↓
Train/Test Split
   ↓
Standardization
   ↓
PCA
   ↓
Model
```

The scaler and PCA should be fitted using training data and then applied to validation/test data.

---

## PCA for Visualization

PCA can reduce high-dimensional data to two dimensions.

For example:

```text
50 Features
     ↓
PCA
     ↓
2 Principal Components
     ↓
2D Visualization
```

This allows high-dimensional datasets to be visualized using PC1 and PC2.

---

## PCA and Target Variables

Standard PCA is generally an **unsupervised** technique.

It focuses on the variance in the input features rather than directly maximizing prediction performance.

Therefore, the component containing the most variance is not necessarily the component that is most useful for predicting the target.

---

## Example

Suppose we have:

```text
Height
Weight
Arm Length
Leg Length
```

Some of these features may be correlated.

PCA could transform them into:

```text
PC1
PC2
```

where each component represents a combination of the original features.

We may then use fewer components while preserving most of the original variance.

---

## Advantages of PCA

* Reduces dimensionality.
* Can reduce redundancy.
* Can improve computational efficiency.
* Useful for visualization.
* Can help reduce noise in some datasets.
* Makes high-dimensional datasets easier to analyze.

---

## Limitations

### Reduced Interpretability

Original features are easy to understand.

Principal components are combinations of many features and can be difficult to interpret.

### Information Loss

Reducing dimensions can discard some information.

### Scaling Sensitivity

PCA is sensitive to feature scale.

### Not Always Necessary

If the dataset has only a few meaningful features, PCA may not provide much benefit.

---

## Feature Selection vs PCA

| Feature Selection          | PCA                          |
| -------------------------- | ---------------------------- |
| Keeps original features    | Creates new components       |
| Removes features           | Transforms features          |
| More interpretable         | Less interpretable           |
| Can use target information | Standard PCA is unsupervised |
| Example: RFE               | Example: PCA                 |

---

## When PCA is Useful

PCA can be useful when:

* There are many numerical features.
* Features are correlated.
* Visualization is required.
* Dimensionality is high.
* Computational efficiency matters.
* Some loss of interpretability is acceptable.

## Key Takeaways

* Dimensionality refers to the number of features.
* Dimensionality Reduction reduces the number of dimensions.
* PCA is a popular dimensionality reduction technique.
* PCA creates new variables called Principal Components.
* PC1 captures the maximum variance.
* Explained Variance Ratio tells us how much variance each component captures.
* PCA is generally unsupervised.
* Features should generally be scaled before PCA.
* PCA can help with visualization and computational efficiency.
* PCA reduces interpretability because the new components are combinations of original features.
