# Day 057: Feature Selection Techniques

## What I Learned

Today I learned about **Feature Selection**, which is the process of selecting the most relevant features from a dataset while removing irrelevant or redundant features.

Feature selection can help reduce noise, improve interpretability, decrease computational cost, and sometimes improve model generalization.

---

## What is Feature Selection?

Feature Selection means choosing the most useful features from the available features.

For example:

```text
100 Features
     ↓
Feature Selection
     ↓
30 Useful Features
     ↓
Machine Learning Model
```

The goal is not simply to reduce the number of features, but to retain the features that provide useful information for the prediction task.

---

## Feature Selection vs Feature Extraction

### Feature Selection

Keeps existing features.

```text
A B C D E
↓
A C E
```

### Feature Extraction

Creates new features from existing ones.

For example:

```text
A + B + C
    ↓
New Feature X
```

PCA is an example of Feature Extraction.

---

# Three Main Feature Selection Methods

The three major categories are:

```text
Feature Selection
       │
 ┌─────┼─────────┐
 ↓     ↓         ↓
Filter Wrapper Embedded
```

---

## 1. Filter Methods

Filter methods use statistical properties to select features without repeatedly training a Machine Learning model.

They are generally fast.

### Correlation

Correlation can be used to identify relationships between numerical features and a target.

Example:

| Feature   | Correlation |
| --------- | ----------: |
| Income    |        0.82 |
| Age       |        0.61 |
| Height    |        0.05 |
| Random ID |        0.01 |

Features with stronger relationships may be investigated first.

However, low correlation does not always mean that a feature is useless because correlation may not capture nonlinear relationships.

---

## Chi-Square Test

The Chi-Square test can be used to examine associations between categorical variables.

For example:

```text
Payment Method
       ↓
   Purchase?
```

It can be useful as a filter method for categorical classification features.

---

## Mutual Information

Mutual Information measures how much information one variable provides about another.

A higher mutual information score indicates that knowing the feature provides more information about the target.

Unlike simple linear correlation, Mutual Information can capture certain nonlinear relationships.

---

# 2. Wrapper Methods

Wrapper methods evaluate feature subsets by training a Machine Learning model and measuring its performance.

The basic process is:

```text
Feature Subset
      ↓
Train Model
      ↓
Evaluate
      ↓
Try Another Subset
      ↓
Compare Results
```

Wrapper methods can be computationally expensive because the model may need to be trained many times.

---

## Recursive Feature Elimination (RFE)

RFE is a popular wrapper technique.

Conceptually:

```text
100 Features
     ↓
Train Model
     ↓
Remove Least Important Features
     ↓
Train Again
     ↓
Repeat
     ↓
10 Selected Features
```

RFE recursively removes less important features until the desired number remains.

---

# 3. Embedded Methods

Embedded methods perform feature selection during model training.

Examples include:

* Lasso Regression
* Decision Trees
* Random Forest
* Gradient Boosting

---

## L1 Regularization / Lasso

Lasso uses **L1 regularization**.

One important property is that L1 regularization can make some model coefficients exactly zero.

Example:

```text
Feature          Coefficient

Age                 0.72
Income              1.31
Height              0
Random_ID           0
Experience          0.48
```

Features with zero coefficients can effectively be excluded from the model.

Therefore, Lasso can perform feature selection.

---

## Tree-Based Feature Importance

Tree-based models can provide feature importance scores.

Example:

```text
Feature              Importance

Income                  0.42
Previous Purchases      0.31
Age                     0.15
City                    0.08
Shoe Size               0.04
```

These scores can help identify potentially important features.

However, feature importance measures have limitations and should be interpreted carefully.

---

# Multicollinearity

Multicollinearity occurs when predictor features are strongly related to each other.

For example:

```text
Age
Age in Months
```

or:

```text
Salary
Annual Income
```

may contain very similar information.

Redundant features can be problematic, particularly for models such as Linear Regression.

---

# Data Leakage in Feature Selection

Feature selection must be performed without using information from the test set.

Incorrect:

```text
Train + Test
     ↓
Feature Selection
     ↓
Train/Test
```

This can cause data leakage.

Correct:

```text
Dataset
   ↓
Train/Test Split
   ↓
Feature Selection on Training Data
   ↓
Apply Selected Features to Test Data
```

The test set should remain unseen during feature selection and model development.

---

# Comparison of Methods

| Method             | Main Idea                      | Speed       |
| ------------------ | ------------------------------ | ----------- |
| Correlation        | Statistical relationship       | Fast        |
| Chi-Square         | Categorical association        | Fast        |
| Mutual Information | Information shared with target | Fast–Medium |
| RFE                | Repeated model training        | Slow        |
| Lasso              | Coefficients can become zero   | Medium      |
| Tree Importance    | Importance from tree models    | Fast–Medium |

---

# Filter vs Wrapper vs Embedded

### Filter

```text
Data
 ↓
Statistical Test
 ↓
Selected Features
 ↓
Model
```

**Select first, model later.**

### Wrapper

```text
Features
 ↓
Train Model
 ↓
Evaluate
 ↓
Select Feature Subset
```

**Uses model performance to select features.**

### Embedded

```text
Features
 ↓
Model Training
 ↓
Feature Selection During Training
 ↓
Final Model
```

**Selection happens inside the learning algorithm.**

---

# Benefits of Feature Selection

Feature selection can provide:

* Reduced computational cost
* Faster training
* Improved interpretability
* Reduced noise
* Smaller datasets
* Potentially better generalization
* Reduced overfitting risk in some cases

---

# Important Note

More features do not automatically mean a worse model.

Sometimes additional features contain valuable information.

Therefore, feature selection should be based on:

* Validation performance
* Domain knowledge
* Model requirements
* Computational constraints
* Interpretability

---

# Overall Machine Learning Workflow

The concepts learned recently can be connected as:

```text
Raw Data
   ↓

   ↓

   ↓
Model Selection
   ↓
Training
   ↓
Cross-Validation
   ↓
Hyperparameter Tuning
   ↓
Final Evaluation
```

---

# Key Takeaways

* Feature Selection chooses the most useful features.
* It can remove irrelevant and redundant information.
* Filter methods use statistical properties.
* Wrapper methods use model performance.
* Embedded methods perform selection during model training.
* Correlation, Chi-Square, Mutual Information, RFE, Lasso, and tree-based importance are common techniques.
* Feature selection must be performed without leaking information from the test set.
* Fewer features are not always better; the goal is to keep useful information.
